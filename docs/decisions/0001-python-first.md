# 0001：第一版使用 Python

## 状态

已接受。

## 背景

项目首要目标是学习计算机网络和亲手验证校园网协议，同时需要为未来跨平台和跨语言迁移保留空间。

## 决策

第一版使用 Python 3.11+ 和模块化命令行程序，网络基础阶段优先使用标准库。

## 理由

Python 便于快速观察 DNS、TCP 和 HTTP 行为，标准库可以减少黑盒依赖。清晰的模型、接口和协议测试向量可以在以后迁移到 Java、Go 或 Rust。

## 后果

第一版不是最终桌面产品，需要后续补充打包、平台验证和桌面界面。协议核心必须避免依赖 Python 特有行为，方便迁移。
