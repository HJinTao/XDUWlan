# 学习文档目录

学习文档按纵向切片实际遇到的主题组织，并同时承担 Python 与计算机网络入门材料的职责。不得只记录 API 用法或最终代码。

每篇文档应按适用范围包含：

1. 本节问题、目标和非目标；
2. 完成本节需要的前置概念，新术语在第一次出现时用中文解释；
3. 当前主题在完整通信路径和网络分层中的位置；
4. 通信参与方，以及域名、IP 地址、端口、URL、协议字段等标识分别属于谁；
5. 从输入到输出的逐步数据流，包括正常路径、可观察现象和当前需要处理的失败；
6. 网络概念与项目文件、类、函数、参数、返回值和测试之间的逐项映射；
7. 当前小步使用的 Python 语法、标准库或第三方库 API；
8. 需要检索的官方 API、协议资料及具体检索问题；
9. 自动化测试条件、预期结果和不进入自动化测试的真实实验步骤；
10. 实现结果、易错点、复盘、当前边界和后续连接点。

涉及网络行为时，文档必须区分概念分层、操作系统或库的实际接口、本项目抽象这三个层次。例如 DNS 文档先解释“主机名为什么需要转换为地址”，再解释操作系统解析器和 `socket.getaddrinfo()`，最后对应到 `DnsResolver` 与 `ResolvedAddress`。知识随代码小步渐进展开，不要求提前讲解尚未使用的整套协议栈。

学习主题按纵向切片实际用到的顺序编写：

1. `00-python-cli.md`：Python CLI 骨架；
2. `01-models-and-config.md`：`status` 使用的枚举、不可变数据和 TOML；
3. `02-dns.md`：DNS 与地址解析；
4. `03-tcp.md`：TCP 连接和超时；
5. `04-http.md`：HTTP 状态码、重定向和 Captive Portal；
6. `05-credentials.md`：Protocol、凭据边界和 keyring；
7. `06-portal-authentication.md`：深澜认证字段、纯函数和 HTTP 客户端；
8. `07-state-machine-and-retry.md`：状态机、退避和可观测性；
9. `08-session-cookie-csrf.md`：会话、验证码、CSRF 和 HTML 解析；
10. `09-packaging.md`：跨平台测试和程序打包。

未来切片的学习文档不提前撰写。实现前先完成当前小步所需的口头网络原理讲解；文档正文在对应代码完成并通过测试后记录实际实现、失败现象和复盘。
