# 协议证据目录

本目录只保存经过脱敏、能够影响实现或测试的协议事实，不承担教学、进度或会话交接职责。

## 证据等级

- **已验证（项目）**：通过自动化测试、本地服务器或纯函数向量验证，只能证明项目契约；
- **已观察（真实）**：来自学习者执行的真实校园网实验，原始数据未进入仓库；
- **推断**：根据页面脚本、字段或通用协议行为推导，尚未实测；
- **待验证**：实现需要答案，但目前没有足够证据。

项目测试通过不等于真实校园网行为已经验证。文档必须明确证据适用范围，不能把本地测试写成线上事实。

## 记录规则

- 不保存真实账号、密码、验证码、Cookie、CSRF Token、challenge、完整认证 URL 或原始 HTML；
- 结论尽量对应到具体测试、脱敏向量或可重复实验条件；
- 证据变化时直接更新对应结论，不维护逐轮观察流水；
- 修改认证实现前必须先添加脱敏证据和失败测试。
