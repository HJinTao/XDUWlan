# 安全与隐私

涉及凭据、认证、协议或真实网络操作时遵守本文件。

## 敏感数据

密码、验证码、Cookie、CSRF Token、challenge、完整认证 URL、认证参数和原始会话页面均按凭据处理。账号、IP、MAC、姓名和设备信息属于个人信息。

这些内容不得进入 Git、普通配置、命令参数、长期环境变量或日志。测试只使用虚构值；实测只记录状态码、错误类别、耗时和脱敏结论。

## 输入与存储

- 密码只从隐藏交互输入或系统凭据库读取。
- configure 不能关闭回显时明确失败，不退回普通输入。
- 长期凭据由 keyring 保存，不静默回退明文文件。
- TOML 只保存非敏感参数，URL 不允许内嵌账号密码。
- 真实凭据仅由账号持有人通过隐藏交互输入，不复制成测试 fixture。

## 网络与输出

- 确认需要认证并校验 Portal 上下文后，才读取凭据。
- 凭据和认证派生值只发往配置中明确指定的 HTTPS 同源端点，保留证书验证。
- 页面导航校验精确主机、协议和端口，不执行 JavaScript，不自动跟随认证重定向。
- 网络请求有超时和正文上限，认证传输不使用代理。
- 所有输出模式只公开固定状态、错误类别、耗时和建议；debug 也不输出原始正文或敏感参数。
- 底层异常先转换为安全项目错误，不直接展示系统或网络异常文本。

## 测试与真实操作

自动化测试使用虚构输入和本地服务，不访问真实校园网或凭据记录。修改协议前先准备脱敏证据和能复现问题的测试；证据等级见 [协议](protocol.md)。

真实操作必须获得设备与账号持有人授权，并限于约定的网络和操作范围。凭据由账号持有人在隐藏终端中输入；授权记录和个人部署信息不写入公开仓库。

不绕过验证码，不自动下线、删除设备、修改账户资料或清理后台认证记录。实验结束不得擅自修改网络连接配置或扩展操作范围。

## 泄漏处置

发现疑似真实秘密时停止提交与传播，只告知影响范围，不重复展示内容。已进入 Git 历史的秘密不能靠追加删除提交解决，须先采取相应凭据失效与历史清理措施。
