# 安全与隐私规则

## 敏感信息

账号、密码、验证码、Cookie、CSRF Token、challenge、认证 URL、MAC、IP、手机号和原始 HTML 均视为敏感或可能包含个人信息的数据。

## 存储

- 密码使用 `keyring` 保存到操作系统凭据库。
- 自服务会话按敏感凭据处理，不提交到 Git。
- 普通配置只保存地址、超时、周期、运营商类型和日志等级等非敏感值。
- 不把密码写入源码、普通配置文件或长期环境变量。

## 日志

默认日志只记录状态变化、错误类别、耗时和重试时间。禁止输出密码、验证码、Cookie、CSRF、challenge 和完整认证 URL。账号、MAC、IP 如确需诊断，必须脱敏。

## 验证码

自服务登录使用人工输入验证码，不实现自动识别、不绕过验证码、不复用无法确认有效的旧验证码。

## 测试和文档

测试 fixture、协议向量和文档只能使用虚构数据。真实网页内容必须先脱敏，且不得把浏览器会话、Cookie 或截图提交到仓库。
